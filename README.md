# Credit Card Default Prediction Using Machine Learning

## Overview

This project explores the application of classical machine learning algorithms to credit card default prediction, with a focus on comparing predictive performance and addressing class imbalance.

## Dataset

- Credit card default dataset
- 30,000 observations
- 24 explanatory variables and one binary target variable

## Methodology

- Data preprocessing and exploratory data analysis
- Comparison of machine learning algorithms, including Decision Trees, KNN, SVM, Random Forest, and AdaBoost
- Class imbalance handling using SMOTE
- Model evaluation using Accuracy, Precision, Recall, F1-score, and AUC

## Results

Random Forest achieved the highest accuracy of 81.56% among the evaluated models, with an F1-score of 0.488 and an AUC of 0.773.
